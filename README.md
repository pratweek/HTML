Topics Covered:

Environment Setup: Installation of VS Code, Live Preview extension, and using Emmet for HTML boilerplates.

HTML Basics: The basic HTML document structure (<!DOCTYPE html>, <html>, <head>, <body>, <title>) and using browser developer tools (Inspect element, modifying the local DOM, and document.designMode).

Essential Tags: Headings (<h1> to <h6>), Paragraphs (<p>), Links (<a> with href and target="_blank"), and Images (<img> with src, alt, and dimensions).

Text Formatting: Bold (<b>), Italic (<i>), Underline (<u>), Line Breaks (<br>), Horizontal Rules (<hr>), Subscript (<sub>), Superscript (<sup>), and Preformatted text (<pre>).

Semantic HTML: Structuring webpages for SEO and readability using <header>, <main>, <footer>, <section>, <article>, <aside>, and <nav>.

Containers: Understanding the difference between block-level elements (<div>) and inline-level elements (<span>).

Lists: Creating Ordered lists (<ol>), Unordered lists (<ul>), List items (<li>), and Definition lists (<dl>, <dt>, <dd>).

Tables: Building data tables using <thead>, <tbody>, <tr>, <th>, <td>, and applying the colspan attribute.

Forms: Gathering user input using <form>, <input> (types including text, tel, email, password, date, radio, and checkbox), <label>, <select>, <option>, <textarea>, and submit buttons.

Media: Embedding videos with the <video> tag (using attributes like controls, autoplay, muted, loop) and embedding external content like YouTube videos using <iframe>.

SEO (Search Engine Optimization): On-page SEO principles, including proper heading hierarchy, meta tags (description, author), clean URL slugs, and adding a favicon.

Performance & Core Web Vitals: Optimizing image and resource sizes, and using Google's Lighthouse to measure LCP (Largest Contentful Paint), INP (Interaction to Next Paint), and CLS (Cumulative Layout Shift).

AI Integration: Utilizing ChatGPT to generate CSS styling and JavaScript interactivity based on provided HTML structures.

Projects: Building the semantic skeletons of a Zomato UI clone and a Developer Portfolio, then styling them via AI.
